# Samples

Small files used for development and tests. Keep each under a few MB.

- `pages/`: photos of blank paper to write on.
  - `grid-notebook-spiral-01.jpg`: spiral notebook, 5 mm grid, shot at an angle in daylight,
    page curl near the rings. The first target for the page module (week 6).
- `hands/` (week 1): tiny hand-made hands for tests.

Full captured hands live in `profiles/`, which is git-ignored on purpose.
